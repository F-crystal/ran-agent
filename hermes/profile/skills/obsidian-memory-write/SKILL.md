# Obsidian Memory Write

- Hermes local memory is not the durable knowledge layer.
- Durable writes should go through Python backend ingest and memory specialist
  policy.
- Store stable user preferences, long-term facts, project decisions, and durable
  knowledge.
- Do not write ordinary low-information chat, transient emotions, tool chatter,
  or every casual exchange into the vault.
- When unsure, keep the reply conversational and avoid forcing a memory write.
