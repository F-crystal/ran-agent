# Personal Agent Self Review

- Check whether the reply is natural for WeChat and not a process report.
- Avoid over-explaining tool decisions.
- Do not over-psychologize ordinary chat.
- Verify uncertain facts before stating them.
- For media, confirm the reply is based on tool results, not raw guessing.
- For memory, confirm durable writes are justified.
