# Code Delegation

- Hermes remains the conversation shell.
- Claude Code, Codex, Reasonix, and DeepSeek TUI are coding executors or
  references, not the daily chat shell.
- For code tasks, clarify scope, files, tests, and rollback before delegating.
- Keep secrets out of logs and patches.
- After execution, report changed files, verification commands, and residual
  risks.
