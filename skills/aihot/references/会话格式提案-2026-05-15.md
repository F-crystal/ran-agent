# 2026-05-15 会话：AI周报格式优化提案

## 背景

陛下反馈当前 AI 周报格式"看着有点儿累"。经讨论，整理出四个优化方向。

## 方案 A：头重脚轻

前 5-8 条精选保留完整 summary（带关键价值点），其余全部缩成 bullet 「标题 — 来源」。
原文 url 全部集中到分类末尾或全文最后。

示例：
```
🔥 本周头条
1. OpenAI累计投入超1000亿 — IT之家
   纳德拉称当年投资时"没人愿意下注"——这改变了整个行业格局

2. Anthropic与盖茨基金会2亿合作 — Anthropic Newsroom

📦 模型发布（5条）
• inclusionAI/ARGenSeg-8B — 蚂蚁 inclusionAI
• Granite Embedding Multilingual R2 — 开源多语言嵌入模型，32K上下文
• Kimi K2.6登顶金融智能体基准榜首

🔗 原文链接：url1 | url2 | url3
```

## 方案 B：按天分组 + 本周关键词

不是按 category 分组，而是按「今天 / 昨天 / 本周早些」来组织。
每段开头加一句本周在这个方向上的观察/关键词。适合让用户扫读时抓住节奏。

## 方案 C：去 URL / 集中到文末

每条后面的 url 拆出来统一放在分类末尾或者全文最后。正文只留「标题 — 来源 — 一句话摘要」。中间不会被链接打断视线。

## 方案 D：用户自定义

直接按用户具体想法调整。

## 当前推荐

综合来看，方案 A + C 的组合效果最好（头重脚轻 + 集中 URL），已在 SKILL.md 主体中以「周报式输出（精简模式）」形式固化。
