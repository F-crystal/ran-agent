## 这份示例可以对照模板理解的要点

1. **头重脚轻**：头条和模型 section 里 top 3 有 summary，第 4-5 条只有标题+来源+时间
2. **summary 写法对比**
   - 好的：`小模型、快推理、成本降 80%`（讲清楚了为什么重要）
   - 差的：`OpenAI 发布了一款新的小型模型`（复述标题）
3. **时间一致性**：全部是 `（今天）`/`（昨天）`/`（M/D）`，没有"刚刚""5小时前"这种不稳定格式
4. **Section 顺序**：头条 → 模型 → 行业 → 产品 → 论文 → 观点 → 快讯
5. **URL 集中**：正文干净，链接全部在最后
