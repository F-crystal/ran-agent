## 使用规则

1. **Section 顺序固定**：头条 → 模型 → 行业 → 产品 → 论文 → 观点 → 快讯
2. **头重脚轻**：每个 section 仅 top 3 条有 summary，第 4 条起纯标题+来源+时间
3. **时间格式**：每条必带 `（今天）` / `（昨天）` / `（M/D）`，用发布时间计算相对时间
4. **Summary 写作**：写为什么重要（takeaway），不是复述标题。~80-100 字。用中文。末尾可以加 `...`
5. **URL 集中**：正文不出现任何 URL。精选最多 12 条原文链接放在文末。超出部分写"共 N 条"
6. **无全局编号**：只用 `•` bullet，不给用户"必须读完 N 条"的压迫感
7. **Section 为空则不输出**：某类没有内容，整段跳过
8. **单条输出**：如果只有 1-3 条，用标准格式（不压缩），每条带 summary
