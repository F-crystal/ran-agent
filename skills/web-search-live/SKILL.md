# Web Search Live

## Use When

- 新闻、价格、政策、产品规格、比赛结果、时间表、版本变更
- 用户明确要求“查一下/搜一下/最新/今天”
- 回答需要外部来源支撑

## Workflow

1. 先用 `web_search` 找 2-3 个高相关来源。
2. 若 `web_search` 结果已足够回答则直接输出；仅在必须读取正文时再用 `web_fetch`。
3. 回复时给出结论 + 来源链接（不贴大段原文）。

## Guardrails

- 不要仅凭记忆回答时间敏感事实。
- 避免 `~` 路径；仅使用绝对路径或工作区相对路径。
- 若 `web_fetch` 因 SSRF/网络策略被拦截，回退到 `web_search` 结果并明确告知“无法直接抓取网页正文”。
