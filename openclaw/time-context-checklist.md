# 时间上下文检查清单

## 何时使用

在以下场景中，AI 应主动检查并确认时间上下文：

## 检查项

### 1. 会话开始时的时间确认
- [ ] 检查当前日期、时间、时区
- [ ] 确认是否为新一天的第一次对话
- [ ] 如是深夜/凌晨，考虑询问用户是否该休息

### 2. 相对时间判断
- [ ] 用户说"明天"、"后天"时，基于当前日期计算准确日期
- [ ] 用户说"待会儿"、"等下"时，考虑当前时间和用户日程
- [ ] 用户说"早上"、"下午"、"晚上"时，结合当前时间判断是否已过去

### 3. 跨天场景
- [ ] 用户熬夜到凌晨 → 建议将当前时间归入"前一天"的延续
- [ ] 用户睡醒后 → 确认是新的一天开始
- [ ] 长对话跨越零点 → 适时提醒用户时间

### 4. 日程相关
- [ ] 创建日程时，确认日期和时间格式正确
- [ ] 设置提醒时，确认时区一致
- [ ] 提醒时间早于当前时间 → 提示用户调整

### 5. 特殊场景
- [ ] 用户提到"昨天"、"上周" → 基于当前日期计算
- [ ] 用户计划未来活动 → 确认日期是否合理
- [ ] 用户回顾过去事件 → 帮助梳理时间线

## 工具支持

使用 `session_status` 工具获取当前会话状态（包括时间信息）

## 注意事项

- 时区：默认使用 Asia/Shanghai（用户所在地）
- 日期格式：YYYY-MM-DD
- 时间格式：HH:MM（24 小时制）
- 不要假设用户的作息习惯，必要时询问
